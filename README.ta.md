## கணக்கீடு எப்படி நடக்கிறது?

HypoNavi **தரநிலை வீட்டுக்கடன் ஆண்டுத்தொகை சூத்திரத்தை** பயன்படுத்துகிறது — ஒழுங்குமுறைக்கு உட்பட்ட ஒவ்வொரு கடன் வழங்குநரும் பயன்படுத்தும் அதே சூத்திரம்:

```
M = P × [ r(1+r)^n / ((1+r)^n − 1) ]
```

இங்கு `M` = ஒரு காலத்திற்கான தவணை, `P` = அசல், `r` = கால வட்டி விகிதம், `n` = மொத்தக் காலங்களின் எண்ணிக்கை. இது "மதிப்பீடு" அல்ல — முடிவு உறுதியானது. ஒரே உள்ளீடுகளைக் கொண்ட இரு கடன்கள் HypoNavi-யிலும், உங்கள் வங்கியின் தள்ளுபடி அட்டவணையிலும், எந்த விரிதாளிலும் ஒரே எண்களையே தரும்.

## கூடுதலாகக் கட்டுவதா, அந்தப் பணத்தை முதலீடு செய்வதா?

உங்கள் முதலீட்டு வருவாயுடன் ஒப்பிடத் தேவையான எண்ணை HypoNavi தருகிறது. **"கூடுதல் தவணை" வார்ப்புருவைத்** திறந்து, நீங்கள் முதலீடு செய்திருக்கக்கூடிய தொகையை உள்ளிட்டால், **மிச்சமாகும் வட்டியும்**, கடனில் இருந்து **குறையும் மாதங்களும்** தெரியும். வரிக்குப் பிந்தைய எதிர்பார்க்கப்படும் வருவாய் *உங்கள் கடன் வட்டியை விட அதிகம்* என்றால், கணக்கு சொல்வது: முதலீடு செய்யுங்கள். *குறைவு* என்றால், முன்கூட்டியே கட்டுங்கள். தானியங்கு நுண்ணறிவுப் பலகம் இந்த வித்தியாசத்தைத் தெளிவாகக் காட்டுகிறது.
