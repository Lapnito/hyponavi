## कब चाहिए?

| स्थिति | HypoNavi दिखाता है |
|--------|-------------------|
| बैंक A vs बैंक B 30 साल | कुल ब्याज + EMI |
| बोनस/विरासत — चुकाएँ या निवेश | एकमुश्त: ब्याज बचत + महीने कम |
| 18 महीने में फिक्सेशन समाप्त | स्ट्रेस टेस्ट +1/+2/+3% |
| फीस के साथ रिफाइनेंस | सटीक break-even महीना |

## गणना

`M = P × [r(1+r)^n / ((1+r)^n − 1)]` — बैंक की EMI टेबल से पैसे तक मेल।

## चुकाएँ या निवेश?

शुद्ध रिटर्न > मॉर्गेज दर → निवेश। कम → चुकाएँ।
